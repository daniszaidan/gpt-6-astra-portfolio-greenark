## Design
An editorial portfolio for a frontend developer with a designer's eye. Oversized tightly tracked sans typography, small monospace annotations, fine rules, purposeful space, asymmetrical projects, a moving typographic ribbon and custom generative line art. Home leads with a bold statement and small identity card. Deep project pages retain all original showcase images. About covers biography, career, education, awards and interests. Add dedicated Expertise, Playground and Contact pages. Certificate archive and printable resume remain first-class pages.

## Architecture
Dependency-free static HTML generated by scripts/build.mjs with shared CSS and progressive-enhancement JS. Each page has complete HTML content before JS. Nested works/{slug}/index.html pages; relative links also work from a local file. Build input is curated data plus an asset manifest. All original image assets stored locally. No backend or fake message delivery: contact composes an email draft in the user's email application.
