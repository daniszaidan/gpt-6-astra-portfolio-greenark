01 / Overview

Every developer starts somewhere.

EndlessCode is an educational website created with Fadli while studying at Telkom University. Built entirely with HTML, CSS, and JavaScript, it explores how to make programming approachable for beginners.

02 / The approach

Remove friction from the first encounter with code. A friendly introduction, organised courses, and lesson playlists give new learners a clear path through the material.

01 /

A welcoming starting point.

The homepage introduces the platform, explains its purpose, and helps beginners find a course that interests them.

02 /

Built from the fundamentals.

Course listings, playlists, testimonials, and a sign-in interface were implemented without a framework—an early exercise in design and development working together.
